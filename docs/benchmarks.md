## GB/T 19246-2003 第 4.4 条

`enginecli --keystroke-eval <句子集> --limit 300 --pages 34`：模拟打字，打完全拼，每次选翻页范围内最长的正确候选；空格或数字算 1 键，翻一页加 1 键。平均码长 = 全部击键 / 字数（标准：拼音 < 3.2 键/字）；重码字词键选率 = 不是第一个候选、用选择键确认的字 / 字数（标准：拼音 < 6%）。
