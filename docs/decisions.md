# 决策记录

已经定下的事，后续开发不再重开。

1. **方案**：词库 + 语言模型 + 本机学习。纯模型生成候选的路线试过（2026-10-08 至 10-12），第一层做不到，放弃。
2. **四个层次的优先级**：一、输入正确（词优先）；二、速度；三、联想（已去掉）；四、学习。上一层不降，下一层才算。
3. **不联网**。沙盒内，没有网络权限，也不会申请。
4. **学习是真正的学习**：微调模型，训练前后校验，变差回滚。不记录选择次数来排序。
5. **不写死规则**。不为具体词、具体场景加特例；一般性的输入惯例（数字后的 . 和 : 保持英文、引号开闭）可以。
6. **标准答案按大众用法**：装机版的候选顺序以大众文本为准；个人偏好只通过本机学习体现。
7. **输入法是打词的工具**：主测试是“在真实前文下打一个词”的首选率，不是整句。
8. **单字母不是单词**；同时有英文和中文候选时中文优先。中文候选指词库里的一个词：几个单字或几个词拼在英文字母上的读法不算（2026-10-19，loading 有前文时被“咯啊定”顶掉）。
9. **联想与预测去掉**（2026-10-16）：键盘上读联想的成本高于省下的字母，实测停顿点命中 15.8%、每次省 0.21 字；标点预测也去掉。候选只来自拼音。
10. **标点直接出中文符号，没有选择面板**（2026-10-20）：中文模式下标点键直接出中文符号（和系统拼音一样），要英文符号切到英文模式；数字后的 . 和 : 保持英文、引号成对照旧。原来的做法是符号先上屏、面板里再换成英文符号或别的写法：换的时候要应用报告并替换光标前的文字，终端不支持（面板一出来就被关掉，Tab、方向键都换不了）；面板开着时数字和方向键改了意思（$100 少一个 1），还有 2 秒的计时。2026-10-18 试过的“正在输入”方式在浏览器、终端里回车要按两次。所以整个面板去掉。
11. **中英文切换**：Caps Lock（亮=英文）和单独按 Shift，都在设置的快捷键里可改；系统的“Caps Lock 切换 ABC”选项对第三方输入法不生效，所以自己实现。
12. **快捷键设置是录键**，不是选项；普通键必须带 ⌘⌃⌥（F 键除外）。
13. **学习后打字回 NPU**：学到的参数写回 Core ML 模型副本；训练留在 GPU；打字时训练暂停。
14. **模型保持 lm9**：16 层的 lm9x 词测试只高 0.1 到 0.3，回放低 1.5，包大 160 MB，学习慢一倍，不采用。
15. **每个例子代表一类问题**，先想清楚类别再改；改一处、测全部、不降才装机。
19. **键盘拼音按 GF 3006-2001《汉语拼音方案的通用键盘表示规范》**（2026-10-20）：字母、声母、韵母直接敲；ü 能省两点的敲 u，不能省的敲 v（lv、nve）；隔音符号敲 '，打字时照原样显示，原样上屏时保留（xi'an）；ê 敲 ea（欸，词库里给 pypinyin 读 ê 的字加上读音 ea，其余行不变）。声调数字（4.4，guo2jia1）不支持：拼音后的数字用来选候选，和系统拼音一样。
20. **对照 GB/T 19246-2003《信息技术 通用键盘汉字输入通用要求》**（2026-10-20）：标点按系统拼音的习惯：` → ·、{ } → 「」、| → ｜；标准表 1 里另有的写法（．、［］、〔〕、〈〉、连接号 — －）不提供，按键也不加（用户 2026-10-20：“按系统习惯就可以了”）。字符集（4.2）：pypinyin 有读音的汉字都能打（41,849 个，基本区 20,923 个），新加的字只取《汉语拼音方案》里已有的音节（方言音 din、wong 和叹词 m、ng 不加），频率在最低一档，放在单独的 rare_characters 表里：放进主表时每次按前缀、首字母查词都要多扫几万行，打字慢 5–25%（同机交替对比），单独放后主表与原来逐行相同、速度回到原来的水平；整段输入是一个音节时列出这个音节的全部字（主表加 rare_characters），翻页可到。这台机器上没有字体能显示的字不列（显示成方框没有用）：扩展 B 区以后的字在输入法里用系统的字体回退逐个查、记住结果（不同 macOS 版本字体不同，所以不在建库时筛）；macOS 27 上扩展 B–F 的 14,687 个只有 929 个能显示，基本区和扩展 A 区全部能显示。读音（4.3.3）对照 1985 年《普通话异读词审音表》：585 个统读字的规定读音词库里都有，按词规定读音的 633 个词全部一致，只有 12 个文言词沿用旧读（仆射 pu ye、期年 ji nian、法家拂士 bi 等）。性能（4.4）见 benchmarks.md。
18. **学习的检验按本人判断，学习率提高**（2026-10-18）：查出学习弱的根本原因是学习率太小（2e-5，本人和三个论坛作者都一样，模型连训练过的话都记不住）。学习率改为 6e-5，检验不过时用 2e-5 重训一次。单独敲词的检验改为本人最近的输入（大众常用词一项只记录不拦截：单独敲词时只有本人打过的词会动，它量到的全是本人的个人化）；大众句子仍不许降超过 1 个点。句子中间的学习提升规则删掉（学习率提高后模型自己就做到同样的效果）；单独敲词的保护（只往上提）保留，根子在出厂模型单独认词弱。
17. **英文词补全、写法按用法定**（2026-10-18）：英文词表取满 5 万词的词频表（只取前 3 万时漏了 dialog 这类常用词）；普通英文词默认小写，只有某种写法在中文文本里占 60% 以上才排第一（OK），占 20% 以上的其他写法作为后面的候选（hello 之后有 Hello），刻意的大小写混写照旧（iPhone、macOS）。原来每个词只给中文文本里最常见的一种写法，常用词里约三成被定成了大写（IT、Hello、School）。英文词测试 30.17% → 32.83%，中文词库逐行不变。
16. **安装包瘦身只做无损的**（2026-10-16）：出厂权重从 Core ML 模型文件里读（去掉 57 MB 的重复拷贝）；词库去掉不读的列和索引并压实（151 → 109 MB）；二元模型改为按行存储、概率用 16 位对数（189 → 98 MB），词对不剪枝：剪到出现 ≥10 次会让对话句集降 0.7、输入法真实语料降 2.3 个点。
