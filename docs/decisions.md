# 项目规则

## 方案

1. 词库 + 语言模型 + 本机学习。词库决定有哪些词；整句读法按通用文本统计出的词频和词对排序；语言模型按上文给整句读法重新排序；本机学习微调语言模型。
2. 优先级：输入正确 → 速度 → 学习。上一层不降，下一层才算。
3. 不联网：在沙盒里运行，没有网络权限。
4. 学习是微调模型：训练前后校验，变差就回滚。不记录选择次数来排序。
5. 不写死规则：不为具体词、具体场景加特例。一般性的输入惯例可以有，例如数字后的 . 和 : 保持英文、引号成对。
6. 装机版的候选顺序按通用文本；学习记录带来的顺序只来自本机学习。
7. 输入法是打词的工具：主测试是“在真实前文下打一个词”的首选率。
8. 一个例子代表一类问题。改一处、测全部、不降才装机。
9. 没有联想和预测：候选只来自拼音。

## 输入

1. 单字母不是单词。同时有英文和中文候选时，中文优先；中文候选指词库里的一个词，几个单字或几个词拼在英文字母上的读法不算。
2. 键盘拼音按 GF 3006-2001《汉语拼音方案的通用键盘表示规范》：字母、声母、韵母直接敲；ü 能省两点时敲 u，不能省时敲 v（lv、nve）；lue、nue 读作 lüe、nüe；隔音符号敲 '，打字时照原样显示，原样上屏时保留（xi'an）；ê 敲 ea（欸）。拼音后的数字用来选候选，不支持声调数字。
3. 标点：中文模式下标点键直接出中文符号，没有选择面板；英文符号在英文模式下打；数字后的 . 和 : 保持英文；引号成对。` 出 ·，{ } 出「」，| 出 ｜。
4. 打名称出符号：50 个两音节以上的名称（引号、括号、书名号、省略号、百分号、摄氏度、箭头、对号、星号、人民币等）对应 75 个符号，放在词库的 symbols 表里，排在名称这个词的后面（yinhao：引号 「」 『』），所以符号永远不是第一个。词库里没有的名称作为词加入，编号排在已有词之后。单音节的名称（du → °）不加。
5. 字符集：pypinyin 有读音的汉字都能打（41,849 个，基本区 20,923 个）。新加的字只取《汉语拼音方案》里已有的音节，频率在最低一档，放在单独的 rare_characters 表里，主表的查询速度不受影响。整段输入是一个音节时，列出这个音节的全部字，翻页可到。这台机器上没有字体能显示的字不列：扩展 B 区以后的字在输入法里用系统的字体回退逐个查，并记住结果。
6. 读音以 1985 年《普通话异读词审音表》为准；12 个文言词沿用旧读（仆射 pu ye、期年 ji nian、法家拂士 bi 等）。
7. ←/→ 在候选之间移动，可以跨页；Tab / Shift+Tab 同样。拼音里不移动光标，打错的字母用删除键改。
8. 中英文切换：单独按 Shift 切换，切换键在设置里可改，也可以加上 Caps Lock（亮 = 英文）。Caps Lock 是大写锁定：亮时字母直接大写上屏，不拼音。设置里没有任何切换键时，恢复为左右 Shift。
9. 快捷键设置是录键；普通键必须带 ⌘⌃⌥，F 键除外。
10. 双拼：设置里“使用双拼”开关（默认关）和“双拼方案”选择；开关关着时方案变灰不能选。方案有小鹤（默认）、自然码、微软、搜狗 4 种，按键表以各方案的公开定义为准，与 fcitx5 的 libime、雾凇拼音一致。
    - 双拼的两个键先换成全拼音节（小鹤 nihc → ni'hao），再交给同一个引擎；候选的长度换回按键数。词库、模型、学习、模糊音都照用。
    - 输入框显示全拼（ni hao），学习按全拼记。
    - 零声母按各方案自己的写法；微软、搜狗的零声母两种打法都收（o 加韵母键；a、e 开头的用首字母加韵母键，如 an 打 aj）。
    - 两个音节落在同一对键上时，取字多的那个（lo 是 luo）。
    - 微软、搜狗的 ing 在 ; 键上：打拼音时，; 跟在还没配韵母的声母键后面就是韵母键。
11. Shift+Delete：打拼音时选中一个候选按 Shift+Delete，撤销学到的这个词（和设置里点标签一样），候选随即重排。
12. 快捷输入：
    - v 加数字出中文和大写（v1234.5 → 一千二百三十四点五、壹仟贰佰叁拾肆点伍、壹仟贰佰叁拾肆元伍角、1,234.5）。
    - v 加算式出结果（v12*3+5 → 41、12*3+5=41；支持 + - * / ^ % 和括号）。
    - vu 加 4–6 位十六进制出字符（vu4e00 → 一）。
    - 只有 v 后面紧跟数字或符号时，数字和符号才进入输入（video、vue 照旧是英文）。
    - 日期、时间、星期、农历四个词后面跟当时的值（riqi → 日期 2026-10-20 …），排在名称之后。
    - 快捷输入、日期时间和符号的结果不记进学习。
13. 模糊音：在设置里逐条勾选，默认全关。一条是一对音，共 12 条：z=zh、c=ch、s=sh、n=l、l=r、f=h、an=ang（只管 lan/lang 这类）、ian=iang、uan=uang、en=eng、in=ing、u=ü。改了下一个键就生效；模糊读法每个音节扣 1。
14. 以词定字：打拼音时 [ 上屏高亮词的第一个字，] 上屏最后一个字（bianji → 编 / 辑），只对两个字以上的中文词；其他时候 [ ] 出【】。这样挑出的字不记进学习。
15. 英文词：英文词表取满 5 万词的词频表。普通英文词默认小写；某种写法在中文文本里占 60% 以上才排第一（OK）；占 20% 以上的其他写法作为后面的候选（hello 之后有 Hello）；刻意的大小写混写照原样（iPhone、macOS）。

## 学习

1. 学到的参数写回 Core ML 模型的副本，打字在神经网络引擎上跑；训练在 GPU 上；打字时训练暂停。
2. 学习率 6e-5；检验不过时用 2e-5 再训一次。
3. 检验：学习记录留出的输入（句子里）和学习记录里最近的输入单独敲时的首选，降超过 0.5 就丢弃；通用句子降超过 1 就丢弃。常用词和“模型学反”只记录，不拦截。
4. 单独敲一个词时，学习只把学习记录里有的词往前提，不往后压。
5. MPSGraph 里的模型权重从 GPU 缓冲区喂入，不做成常量：常量会被写到磁盘。

## 数据与模型

1. 训练数据和测试数据都用清洗后的版本；验证集和所有测试集的上文也清洗过，目标句不受影响。
2. 清洗：个人信息换成“＊”，规则只有一份（`Resources/redaction.json`），训练数据和学习记录共用；去掉页面结构和不是打出来的行。规则明细见 `docs/development.md`。
3. 去重：整篇重复、反复出现的长句、文档类来源里出现 20 次以上的模板短行；和留出文本相同的内容不进训练。
4. 按模型打分过滤：只删网页最差的 3%。论坛、混合、新闻不删：它们分数最差的是古诗词、文言、百科、港式新闻，都是正常内容。分数线每类看过样本再定，不套公式。
5. 判定只看判定集（`Data/fresh/`）：清洗后的留出文本，训练数据里一条都没有，不用来调任何东西。防退步句子集（`Data/eval_*.tsv`）只用来防退步。
6. 词频、英文写法、词库、二元模型都从训练模型用的同一份清洗后数据统计。
7. 模型：8 层、512 宽、8 头、窗口 64 的字级 GPT，词表 9026。出厂模型是 clean3。
8. 每一份原始数据都登记在 `Data/manifest.tsv`：路径、下载方式、固定版本的地址、sha256。只提供当前版本的来源标为 `latest`。
9. 安装包只做无损的压缩：出厂权重从 Core ML 模型文件里读；词库去掉不读的列和索引并压实；二元模型按行存储、概率用 16 位对数；词对不剪枝，保留出现 3 次以上的。
